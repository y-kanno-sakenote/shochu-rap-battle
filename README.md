# 焼酎ラップバトル

本格焼酎の5種（芋・麦・米・黒糖・泡盛）どうしがラップで張り合う遊びのページです。対戦カードを2枚選ぶと、名勝負の歌詞を組み替えてバトルが出ます。

- 遊ぶ: https://y-kanno-sakenote.github.io/shochu-rap-battle/
- キャラ: 芋焼酎／麦焼酎／米焼酎／黒糖焼酎／泡盛

## 歌詞について

- 歌詞はAI（Claude）で書いたものです。`docs/shochu_corpus.jsonl` の名勝負から、同じ相手・同じ韻の2行ずつを組み替えて表示します
- 焼酎についての話は、日本醸造協会誌の記事などの資料にもとづく範囲に絞っています
- なかま: [醸造ラップバトル](https://jozorap.sakenote.net/)／[ワインラップバトル](https://y-kanno-sakenote.github.io/wine-rap-battle/)
- 作成: 合同会社サケノテ（sakenote.net）
